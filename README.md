# SmartInventory

บอกว่าทำได้อีกกี่หน่วย อะไรหมดก่อน และต้องซื้ออะไรเพิ่มถ้าอยากทำให้ถึงเป้า

- `landing_page.html` หน้าแรก
- `index.html` แอปคำนวณสต๊อก

ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์
